# Folded-coded CNNs

Opened 2018-02-12.

Keras and TensorFlow experiments on binary and folded CNN variants. Architectures are stored in `modeldatabase/Binary_models`. `sci_circular.py` and `scientists.py` run the circular and folded training. An older interface in the tree parses a text description of a model. That interface was already marked outdated.

## Papers

- Amir Emad Marvasti, Ehsan Emad Marvasti, and Ulas Bagci. [Out of Distribution Detection, Generalization, and Robustness Triangle with Maximum Probability Theorem](https://arxiv.org/abs/2203.12145). *ICECCME*, 2022.
